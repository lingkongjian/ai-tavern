## AI 酒馆 0.1.11（macOS Apple Silicon）

本地优先、由玩家掌握角色控制权的 AI 互动叙事工具。本包为 macOS arm64 便携桌面包，内置 Next.js 本地服务与 SQLite 数据库。

### 下载与安装
- **AI-Tavern-0.1.11-macOS-arm64.dmg**（或同名 .zip）即本机中文名 `AI酒馆-0.1.11-macOS-arm64.dmg` 的安装包
- 解压或挂载后，把整个“AI酒馆”文件夹复制到你的程序目录
- 保持 `AI酒馆.app` 与 `用户数据` 同级（所有运行数据都写入该文件夹）
- 首次启动后，从主菜单进入“API 配置”设置模型供应商（内置 DeepSeek 与 OpenCode Go 预设）

### 本版本更新（0.1.11）
- 回合生成支持 SSE 流式传输，界面以进度条 + 已生成字数实时反馈
- 支持保存多套 API 配置，可在设置面板管理、在游戏页顶栏快速切换
- 当前 API 发生服务端错误/超时/空回复时，自动切换到备用配置重试
- 修复 OpenCode Go 推理模型思维链占满输出预算导致的空回复与截断问题
- 模型目录按协议分层（Chat Completions / Messages / Responses），不兼容模型会明确提示

- 数据与 API Key 全部保存在本机“用户数据”目录，退出后删除整个文件夹即可卸载
