## AI 酒馆 0.1.28（macOS Apple Silicon）

本地优先、由玩家掌握角色控制权的 AI 互动叙事工具。本包为 macOS arm64 便携桌面包，内置 Next.js 本地服务与 SQLite 数据库。

### 下载与安装
- **AI-Tavern-0.1.28-macOS-arm64.dmg**（或同名 .zip）即本机中文名 `AI酒馆-0.1.28-macOS-arm64.dmg` 的安装包
- 解压或挂载后，把整个“AI酒馆”文件夹复制到你的程序目录
- 保持 `AI酒馆.app` 与 `用户数据` 同级（所有运行数据都写入该文件夹）
- 首次启动后，从主菜单进入“API 配置”设置模型供应商（内置 DeepSeek 与 OpenCode Go 预设）；主菜单页脚显示当前安装版本号

### 本版本更新（0.1.27 ~ 0.1.28）
- **生成回合前的回合模式切换**：剧情驱动时间模式下，生成新回合前可以选择——**详细描写场景**（时间保持不变，AI 详细展开你提供的场景：环境、在场人物、氛围、感官细节）或**场景推进**（时间按剧情正常推进，AI 以你的场景为起点描写接下来发生的事）。选择这两种模式时需填写“场景”内容（最多 2000 字），可与角色言行、想法、剧情走向同时使用，场景为主要内容来源。五回合一天模式不提供此切换。
- **全局 UI 打磨**：主菜单与二级页面宽屏左右分区（窄屏自动单列）、游戏页正文与状态栏独立滚动（平板两列、手机单列）、顶部快捷操作栏保留；主要提交操作统一为橙色实心按钮，辅助操作统一为描边按钮；操作手册补充界面布局说明。
