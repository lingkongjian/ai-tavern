## AI 酒馆 0.1.15（macOS Apple Silicon）

本地优先、由玩家掌握角色控制权的 AI 互动叙事工具。本包为 macOS arm64 便携桌面包，内置 Next.js 本地服务与 SQLite 数据库。

### 下载与安装
- **AI-Tavern-0.1.15-macOS-arm64.dmg**（或同名 .zip）即本机中文名 `AI酒馆-0.1.15-macOS-arm64.dmg` 的安装包
- 解压或挂载后，把整个“AI酒馆”文件夹复制到你的程序目录
- 保持 `AI酒馆.app` 与 `用户数据` 同级（所有运行数据都写入该文件夹）
- 首次启动后，从主菜单进入“API 配置”设置模型供应商（内置 DeepSeek 与 OpenCode Go 预设）；主菜单页脚显示当前安装版本号

### 本版本更新（0.1.13 ~ 0.1.15）
- **游戏内时间系统**：每回合默认推进一天，模型可按剧情用 moment/hours/one_day/several_days 覆盖；游戏页顶部显示当前日期；历史回看显示该回合当时的日期；任务可声明 deadlineDay，期限已至会在剧情中强制显现后果
- **地点与离场角色**：剧本包可预注册全部可能出现的地点（含常驻角色与重要性）；游戏页“地图”弹窗展示全部地点、描述与当前位置人物；不在场角色可随剧情显式移动（返回宅邸、前往城外）
- **初始关系（双向）**：剧本包可声明开局关系（信任/好感/恐惧/敌意/敬意），自动建立双向记录；人物管理新增“角色关系”面板实时查看数值与描述
- **防重复续写**：与上一回合高度重复的场景会被自动判定并触发推进重写，避免剧情卡死循环
- 多套 API 配置管理、游戏内快速切换（顶栏左侧）、失败自动切换备用 API（0.1.10 起）
- SSE 流式传输 + 进度条反馈（0.1.11 起）
- 剧本包导入完整性修复：初始关系与地点清单随剧本包正确透传到开局
