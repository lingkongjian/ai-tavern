# AI 酒馆 0.1.31（本地 Windows 移植修订版）

- 模型设置新增“单次输出上限（Token，含思考）”和“生成等待上限（秒）”，分别随 API 配置保存、编辑和切换，下一回合与重生成均生效。
- 旧配置仍默认 6000 Token；本地等待 1800 秒，云端等待 90 秒。LM Studio 的 thinking 模型可从 16384 Token、3600 秒开始调整；输入加输出必须适合加载模型的上下文容量。更高额度不能保证模型及时结束思考。
- 收到 `finish_reason: length` 时提示当前额度及调整方法，不保存截断的回合，也不自动切换备用模型。思考字段不会混入剧情 JSON。
- 可用性审核仍是 64 Token、30 秒的短时测试；开启长思考可能使审核失败，不能据此判断完整回合不可用。

Windows 升级请退出旧版，备份原“用户数据”，完整解压新版后复制数据目录；不要仅替换 EXE。桌面包尚未签名。
