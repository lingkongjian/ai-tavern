## AI 酒馆 0.1.20（macOS Apple Silicon）

本地优先、由玩家掌握角色控制权的 AI 互动叙事工具。本包为 macOS arm64 便携桌面包，内置 Next.js 本地服务与 SQLite 数据库。

### 下载与安装
- **AI-Tavern-0.1.20-macOS-arm64.dmg**（或同名 .zip）即本机中文名 `AI酒馆-0.1.20-macOS-arm64.dmg` 的安装包
- 解压或挂载后，把整个“AI酒馆”文件夹复制到你的程序目录
- 保持 `AI酒馆.app` 与 `用户数据` 同级（所有运行数据都写入该文件夹）
- 首次启动后，从主菜单进入“API 配置”设置模型供应商（内置 DeepSeek 与 OpenCode Go 预设）；主菜单页脚显示当前安装版本号

### 本版本更新（0.1.19 ~ 0.1.20）
- **修复切换分支后生成下一回合报“本轮没有保存”**：回合生成/重生成/判定结算/内容命令/状态审计在途时切换分支或恢复存档，服务端返回的旧分支响应会被前端丢弃，不再覆盖新分支界面；随后提交携带正确的新分支头，避免被服务端 409 拒绝。本轮已在原分支保存，玩家可直接在当前分支重新提交。
- **主线身份可转移**：分支面板任意支线可“设为主线”，主线标志随之一并转移（每剧本恰好一个主线）；删除保护跟随新主线，原主线变为普通支线（没有子分支时可以删除）。完整存档升至 **1.9.0**，旧档导入按“根分支即主线”派生，1.0.0~1.8.0 存档全部兼容。
