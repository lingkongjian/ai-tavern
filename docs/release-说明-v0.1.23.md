## AI 酒馆 0.1.23（macOS Apple Silicon）

本地优先、由玩家掌握角色控制权的 AI 互动叙事工具。本包为 macOS arm64 便携桌面包，内置 Next.js 本地服务与 SQLite 数据库。

### 下载与安装
- **AI-Tavern-0.1.23-macOS-arm64.dmg**（或同名 .zip）即本机中文名 `AI酒馆-0.1.23-macOS-arm64.dmg` 的安装包
- 解压或挂载后，把整个“AI酒馆”文件夹复制到你的程序目录
- 保持 `AI酒馆.app` 与 `用户数据` 同级（所有运行数据都写入该文件夹）
- 首次启动后，从主菜单进入“API 配置”设置模型供应商（内置 DeepSeek 与 OpenCode Go 预设）；主菜单页脚显示当前安装版本号

### 本版本更新（0.1.22 ~ 0.1.23）
- **游戏内时间模式（开局配置）**：新建剧本时可在第一幕表单选择时间模式（导入剧本包时按 `adventure.timeMode` 可选声明预填、可修改），开局后确定、游戏中不可切换。`剧情驱动`模式保持原有语义（时间只随剧情显式推进）；新增 `五回合一天` 模式：每个回合固定推进一个时段（早上→上午→中午→下午→晚上），每 5 个回合进入下一天，适合跑团式剧本；模式内置高效推进约束（每回合承载一个时段的实质进展），任务期限与状态词条到期按天计算（一天 = 5 个回合）。
- **游戏内日期显式化**：`sceneTransition` 新增 `gameTimeDayNext` 可选字段，模型可显式声明本回合结束日期（与 `timeAdvance` 同时提供时以日期为准，语义冲突只警告不拒绝）；正文出现“次日/翌日/数日后”等时间短语而本轮未声明日期推进时，产生时间短语一致性警告（不拒绝回合），提示模型显式声明日期。历史回看已支持显示当时游戏内日期。
- **状态词条随日期与正文同步识别**：跨日推进（一天或数天）时系统强制逐角色演化全部进行中的状态词条（规则 29：debuff 更新描述与到期日、解除后移除，buff 判断消退或延续）；上下文为每项词条注入剩余天数 `daysRemaining` 与当前游戏内日期供模型对照；正文出现某角色可见词条而未同步更新其词条时产生一致性警告，随回合入库并在页面“本轮变化-模型提示”展示。
- **地点一致性校验**：正文、事件描写的场景地点必须与 `sceneTransition` 一致——场景移动时 `locationId` 必须指向正文实际到达的地点，未移动的回合沿用上一轮 ID；正文出现与目标地点不同的已知地点名且场景确在移动时产生地点一致性警告（不拒绝回合），在“本轮变化-模型提示”展示。
- **角色言行权重提升**：玩家角色言行升级为系统消息最高优先级规则（规则 31）——玩家说话时在场角色必须回应、行动时必须呈现结果，剧情走向只能在其后推进；上下文新增 `latestPlayerRoleplay` 高亮分区（置于上下文最前），近期回合的玩家言行带 `mode` 标注（说话/动作/混合），帮助模型保持历史行为一致性。
- **长剧情防兜圈子**：新增跨回合重复检测——本轮场景与最近 4 回合逐一比较，任一高度相似即要求重写，拦截“隔几回合绕回”的长剧情循环；规则 30 明确不得重复此前出现过的方案、桥段、对话模式与场景结论；章节摘要升级为结构化组合（关系变化、地点移动与事件摘要聚合，结构化内容过少时回退原拼接，总长限制 3200 字符），作为旧信息参考而非可重复表演的内容。
- **成人内容生成调整**：重要信息（线索、协议、秘密、关键对话）可能隐藏在包括亲密场景在内的任何场景中，模型必须完整描写以传递信息，不得因题材回避删改或跳过；本地程序不设成人内容安全边界（由所配置的 API 供应商输出审核自行甄别），本地仅保留虚构叙事定位与未成年人底线；玩家控制权不放松——不得替玩家同意或完成玩家未输入的亲密行为，婚约、既往关系与原作剧情不等于当前同意，身份不明确的角色不得参与亲密内容。
- **修复开局初始关系被覆盖**：建立世界物化初始关系时，玩家→其他角色声明的初始关系值不再被默认零值覆盖（声明中已显式给出反向的以声明为准）。
