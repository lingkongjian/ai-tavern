## AI 酒馆 0.1.22（macOS Apple Silicon）

本地优先、由玩家掌握角色控制权的 AI 互动叙事工具。本包为 macOS arm64 便携桌面包，内置 Next.js 本地服务与 SQLite 数据库。

### 下载与安装
- **AI-Tavern-0.1.22-macOS-arm64.dmg**（或同名 .zip）即本机中文名 `AI酒馆-0.1.22-macOS-arm64.dmg` 的安装包
- 解压或挂载后，把整个“AI酒馆”文件夹复制到你的程序目录
- 保持 `AI酒馆.app` 与 `用户数据` 同级（所有运行数据都写入该文件夹）
- 首次启动后，从主菜单进入“API 配置”设置模型供应商（内置 DeepSeek 与 OpenCode Go 预设）；主菜单页脚显示当前安装版本号

### 本版本更新（0.1.21 ~ 0.1.22）
- **角色状态词条系统**：角色身上的 buff/debuff（受伤、中毒、增益等）以结构化词条记录（含名称、类别、描述、来源回合与到期日），模型可在每回合通过结构化变化整体增删，人物管理可查看并增删词条（增益/减益区分显示、带到期日）。词条随剧情增减或恶化恢复；存在负面状态且有解决办法时，角色行动与候选选项会倾向处理（求医、解毒、治疗、休息等）。
- **隐藏状态与探索解锁**：角色未察觉的隐藏状态（暗伤、被下毒、血脉异常等）以导演级信息注入模型、对角色可见信息脱敏，未经察觉不得点破；角色通过剧情探索（检查伤口、求医、观察症状等）认识到后，词条解锁为可见状态。
- **状态词条到期自动移除**：带游戏内到期日的词条在到达到期日时由系统在回合提交事务内自动移除并写入状态变化记录，不依赖模型自觉。
- **剧本包初始状态提取**：剧本包新增 `initialStatuses` 分区声明人物开局状态词条（每角色最多 20 条、最多 60 个角色；未察觉的状态自动标记为隐藏）；从原文生成剧本包时模型会提取人物开局状态，建立世界时自动物化为各角色的状态词条。词条若携带来源回合会产生导入警告并被忽略。
- **剧情任务期限到期兜底**：`deadlineDay` 到达当天仍未完成的任务由系统确定性标记为 `expired` 终态并锁定：不再注入为当前任务、不再作为接续或推荐对象、任务管理禁止编辑与切换；`expiredDeadlines` 硬事实提示在标记后仍持续注入，剧情后果仍由模型显现，玩家保有回应权。
- **旧存档主线确定性派生**：旧版完整存档存在多个根分支或不可信主线标记时，导入不再因唯一索引冲突整体失败；系统按“无分叉点优先、创建时间最早、ID 字典序”确定性派生唯一主线，并返回 `legacyMainDerivation` 导入报告；1.9.0 新档仍严格校验恰好一个主线。
- **状态变化证据强制至少 1 条**：角色状态、关系、角色卡、世界书、伏笔与触发器六类结构化变化的证据列表显式强制至少 1 条真实事件引用（剧情方向评估在未完成时除外），防止无依据的状态写入。
- **触发器期限与初始状态校验加固**：偏离触发器 `deadline` 仅允许省略或 null 表示无期限，0/负数/小数/非数字一律拒绝；触发器关系维度断言与白名单常量绑定，未来维度变更编译期可发现。
- **审查清理**：补齐 drizzle schema 表定义（`turn_context_snapshots`）、删除死导出与只写不读字段写入，三方核对通过。
