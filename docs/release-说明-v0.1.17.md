## AI 酒馆 0.1.17（macOS Apple Silicon）

本地优先、由玩家掌握角色控制权的 AI 互动叙事工具。本包为 macOS arm64 便携桌面包，内置 Next.js 本地服务与 SQLite 数据库。

### 下载与安装
- **AI-Tavern-0.1.17-macOS-arm64.dmg**（或同名 .zip）即本机中文名 `AI酒馆-0.1.17-macOS-arm64.dmg` 的安装包
- 解压或挂载后，把整个“AI酒馆”文件夹复制到你的程序目录
- 保持 `AI酒馆.app` 与 `用户数据` 同级（所有运行数据都写入该文件夹）
- 首次启动后，从主菜单进入“API 配置”设置模型供应商（内置 DeepSeek 与 OpenCode Go 预设）；主菜单页脚显示当前安装版本号

### 本版本更新（0.1.16 ~ 0.1.17）
- **修复完整剧本包导入后伏笔与触发器未生效**：开局导入剧本包时伏笔（foreshadowing）与偏离触发器（triggers）分区会随“建立世界”一并物化为游戏内实体，可从工作台“伏笔”“触发器”栏目查看；导入摘要会显示“伏笔 N 条、偏离触发器 N 个”
- **伏笔系统**：剧本包可声明跨章节伏笔（出现条件满足时埋入、回收条件满足时呈现概要），与剧情任务互补，解决短上下文下跨章节伏笔真正目的丢失的问题
- **偏离触发器**：剧本包可声明偏离原剧情时的意外阻碍（条件满足即触发），系统强制应用关系/属性/bad_end 标志等状态影响；支持 `deadline` 期限，超过游戏内期限后强制触发；bad_end 置位后游戏页显示结局警示横幅
- **属性判定**：角色具备可成长属性（力量/敏捷/感知/意志/魅力/智力/体质，0-100）；关键行动弹出“属性 vs 难度 + 骰子”面板，由玩家掷骰、系统确定性结算并回填事实，判定记录可回看
- **工作台新增“伏笔”“触发器”栏目**：统一剧本工作台扩展为九个栏目，伏笔与触发器可编辑与删除
- **关系维度统一为 `affection`**：剧本包初始关系的好感维度改用 `affection`，旧别名 `affinity` 仍兼容导入
- **场景校验放宽**：回合场景切换的地点信息仅在发现新地点时必填，已有地点以本地资料为准
- 完整存档升至 1.8.0，覆盖伏笔、偏离触发器与属性判定的管理审计；1.7.0 及更早存档仍可导入
