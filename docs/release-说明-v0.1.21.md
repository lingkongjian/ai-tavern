## AI 酒馆 0.1.21（macOS Apple Silicon）

本地优先、由玩家掌握角色控制权的 AI 互动叙事工具。本包为 macOS arm64 便携桌面包，内置 Next.js 本地服务与 SQLite 数据库。

### 下载与安装
- **AI-Tavern-0.1.21-macOS-arm64.dmg**（或同名 .zip）即本机中文名 `AI酒馆-0.1.21-macOS-arm64.dmg` 的安装包
- 解压或挂载后，把整个“AI酒馆”文件夹复制到你的程序目录
- 保持 `AI酒馆.app` 与 `用户数据` 同级（所有运行数据都写入该文件夹）
- 首次启动后，从主菜单进入“API 配置”设置模型供应商（内置 DeepSeek 与 OpenCode Go 预设）；主菜单页脚显示当前安装版本号

### 本版本更新（0.1.20 ~ 0.1.21）
- **修复切换分支后提交回合报 UNIQUE constraint failed: messages.id**：回合服务不再把模型输出的事件/对话 id 原样作为全局主键（模型 id 不稳定，切换分支后新回合复用相同 id 会与另一分支或更早回合冲突），存储层一律由服务端生成唯一主键；模型 id 仍保留在原始输出中用于证据引用与审计，不受影响。切换分支后重新提交回合不再报错。
- **设为主线时重组分支树**：任意支线“设为主线”后，新主线会吸收原主线及父链在分叉点之前的历史，成为一条历史完整的主线根；原主线及其父链变为新主线的子分支（分叉点之后各自推进的内容保留并重排；没有推进过则成为空分支，可从分叉点继续发展新路线或删除）。状态变更、审计、快照、恢复点等关联记录随被转移回合一起迁移，自动快照与分叉快照规则保持一致，完整存档无需重新导入。
