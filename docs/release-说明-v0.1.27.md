## AI 酒馆 0.1.27（macOS Apple Silicon）

本地优先、由玩家掌握角色控制权的 AI 互动叙事工具。本包为 macOS arm64 便携桌面包，内置 Next.js 本地服务与 SQLite 数据库。

### 下载与安装
- **AI-Tavern-0.1.27-macOS-arm64.dmg**（或同名 .zip）即本机中文名 `AI酒馆-0.1.27-macOS-arm64.dmg` 的安装包
- 解压或挂载后，把整个“AI酒馆”文件夹复制到你的程序目录
- 保持 `AI酒馆.app` 与 `用户数据` 同级（所有运行数据都写入该文件夹）
- 首次启动后，从主菜单进入“API 配置”设置模型供应商（内置 DeepSeek 与 OpenCode Go 预设）；主菜单页脚显示当前安装版本号

### 本版本更新（0.1.26 ~ 0.1.27）
- **紧急修复 SSE 流启动崩溃（“本轮没有保存 Failed to fetch”）**：上一版引入的中断功能在 SSE 路由中使用了运行时不可用的 `controller.signal`（Node/Next.js 下为 `undefined`），导致流在启动阶段抛错崩溃，AI 回合无法正常生成且提示“本轮没有保存”。本版改用标准 `ReadableStream` cancel 回调标记取消，`request.signal` 监听加可选链保护，turns 与 regenerate 两处路由同步修复。
- **中断功能语义不变**：手动中断后“断连不提交”（中断的回合不写入存档）依然生效，只是改为通过 cancel 回调实现。
