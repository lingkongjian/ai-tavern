# 移交提示词：测试资料与端到端验证

> 用途：在新对话中启动"测试资料维护与端到端验证"工作流时，把本文件全部内容粘贴给新对话。
> 本进程只维护测试资料（剧本包、开局预设、校验报告、验证脚本），不修改产品代码；发现产品 bug 时记录并转交开发进程。

## 项目背景

AI 酒馆（Next.js 16 + React 19 + SQLite + Electron）。测试资料目录：`测试资料/霜火人间_外传第一部/`（被 `.gitignore` 排除，不进公开仓库，仅为本地测试用）。

## 工作流铁律

1. 测试资料修改**只保留在本地**，不提交、不推送（gitignore 已排除）。
2. Node 不在 PATH：`export PATH="$HOME/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin:$PATH"`。
3. 任何剧本包相关的新准则/新分区发布后，本进程负责把测试资料同步到最新准则。
4. 端到端验证使用临时 SQLite 数据库（`mkdtempSync` + `openLocalDatabase` + `drizzle` 迁移目录），**绝不写入正式存档**（运行版数据在 `/Applications/AI酒馆/用户数据/数据/ai-tavern.sqlite`）。


## 端到端验证模板（临时库）

1. `parseAdventureBundleDocument(完整包)` → `store.startAdventure(parsed.adventure)` → `loadAdventure`。
2. 断言：地点实体数（8 预注册 + 1 开场地点）、关系双向（`李长安→林听雪` 与反向均存在且数值一致）、任务期限物化、`gameTimeDay=1`、开场阵容。
3. 可选：注入 mock `generate` 推进回合，验证时间推进、`offstageUpdates` 物化、deadline 到期注入（参照 `tests/时间与地点.test.mjs`）。
4. 完成后关闭数据库并 `rmSync` 临时目录。
