## AI 酒馆 0.1.25（macOS Apple Silicon）

本地优先、由玩家掌握角色控制权的 AI 互动叙事工具。本包为 macOS arm64 便携桌面包，内置 Next.js 本地服务与 SQLite 数据库。

### 下载与安装
- **AI-Tavern-0.1.25-macOS-arm64.dmg**（或同名 .zip）即本机中文名 `AI酒馆-0.1.25-macOS-arm64.dmg` 的安装包
- 解压或挂载后，把整个“AI酒馆”文件夹复制到你的程序目录
- 保持 `AI酒馆.app` 与 `用户数据` 同级（所有运行数据都写入该文件夹）
- 首次启动后，从主菜单进入“API 配置”设置模型供应商（内置 DeepSeek 与 OpenCode Go 预设）；主菜单页脚显示当前安装版本号

### 本版本更新（0.1.24 ~ 0.1.25）
- **伏笔与触发器工作台 UI 增强**：伏笔、偏离触发器栏目改为卡片化展示，带状态徽章（待埋入/已埋入/已回收、待触发/已触发/已失效），完整展示各分区（触发条件、状态影响、bad_end 标志等）；长文本卡片支持截断展开；新增按状态筛选，便于管理大型剧本中的伏笔与触发器清单。
- **API 自动切换持久化**：当前配置调用失败自动切换到备用配置后，备用配置会**持久启用**（不再回跳），顶栏与实际生效配置同步显示；手动切换回原配置后恢复常规行为。
- **AI 写作中可手动中断**：回合生成/重生成过程中可随时点击“中断”停止本次生成，输入内容保留、可修改后重新生成；若生成已在中断前完成，页面会提示并展示最新回合；服务端断连时不会提交半截回合，刷新页面兜底恢复。
- **角色内心想法体系**：AI 角色可拥有内心独白（`characterThoughts`，角色之间互相不知道、玩家角色也不知道，只塑造言行一致性），玩家角色可随言行提交内心想法（`innerThoughts`，限长 1000 字，影响言行风格与选项倾向）；正文与对话不得直接写出他人想法，想法不自动成为言行。页面新增折叠“内心活动”分区，历史回合回看同样可见。
- **已知信息追踪**：角色获知的重要信息（对话告知、信件、发现、偷听等）按角色登记（`knownFacts`，按角色隔离）；已登记的信息不再重复“首次获知”表述，剧情推进到相关情节时体现角色已掌握信息。
- **关系维度区分**：信任（托付秘密、可靠守约）与好感（心动、亲近、思念）明确为不同维度，关系加深必须判断本次加深的是哪一边（兼有时分别登记），不得笼统“关系加深”。
- **次要人物名录登记**：剧情中随口提到的未建卡背景 NPC（亲人、邻居、路人等）自动登记进次要人物名录（`minorCharacterUpdates` → `minor_character`），防止长上下文后 NPC 名字漂移；已登记角色重提必须沿用原名；名录不进入可扮演角色列表。
- **关系定性类型与转化**：角色关系带定性类型（`relationshipType`：家人/情侣/朋友/对手/同侪/同盟/泛泛之交/其他），剧本包可声明初始类型；回合可提交 `typeChange` 表达定性转化（如姐弟经调查发现无血缘后转为朋友、再发展为情侣），转化必须伴随真实剧情事件，转化历史保持审计记录（from→to，不抹去“曾是姐弟”），与五维度数值解耦。
